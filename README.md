# Judith's Kenya Tours

A website for tours around Kenya, near Nairobi. All tours are led by Judith, an independent tour guide based near Nairobi.

Built with [Next.js](https://nextjs.org), React, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
